# Weather Lens

A simple weather app built with React that shows real-time weather data for any city worldwide.

## Live Demo
[Weather Lens](https://alamin-weather-lens.vercel.app/)

---

## Tech Stack
- React + Vite
- Tailwind CSS
- Lucide React
- Context API
- OpenWeatherMap API

---

## Getting Started

```bash
git clone https://github.com/alamin-one/weather-lens.git
cd weather-lens
npm install
npm run dev
```
